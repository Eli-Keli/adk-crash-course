# ADK Crash Course - Agent Development Kit Learning Repository

> 🚧 **Work in Progress** - This repository is being actively developed. Check back soon for complete learning materials!

## 📚 About This Repository

This repository contains hands-on examples and tutorials for learning the **Google Agent Development Kit (ADK)**. Each branch represents a different part of the crash course, allowing you to easily navigate and learn at your own pace.

## 🎯 Learning Path

Follow the branches in order to build your ADK skills:

### ✅ Part 1: Basic Agent (Current)
**Branch**: `part-1-basic-agent`  
Learn how to create your first AI agent with built-in tools.

### 🔜 Coming Soon
- Part 2: Custom Tools & Agent Teams
- Part 3: Memory & Sessions
- And more...

## 🚀 Getting Started

1. **Clone this repository**:
   ```bash
   git clone <your-repo-url>
   cd adk-crash-course
   ```

2. **Checkout the branch you want to learn**:
   ```bash
   git checkout part-1-basic-agent
   ```

3. **Follow the instructions** in that branch's README or instructions file.
